## Overview

Piano Note Trainer brings note-reading practice to the browser through exercises centered on piano note recognition. It gives learners a simple way to become more familiar with written musical notes in a piano-focused learning environment.

The trainer can fit into the routines of students, instructors, and self-directed musicians. Since it runs on the web, practice can begin in a compatible browser without installing a separate desktop program.
